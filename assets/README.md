# Картинки

Пути прописаны в `index.html` (ищите `--img:url(`). Пока файла нет — на его
месте видна полосатая песочная заглушка.

## Подключено

| Файл | Что на ней | Где на сайте |
|---|---|---|
| `hero.webp` | компания у жёлтого фургона в горах | большой квадрат справа в первом экране |
| `cat-1.webp` | сантехник с разводным ключом | плитка «Ремонт и быт» |
| `cat-2.webp` | курьер с коробками и телефоном | плитка «Курьерские задачи» |
| `cat-3.webp` | разработчик за мониторами | плитка «IT и разработка» |
| `cat-4.webp` | уборка со шваброй | плитка «Уборка и клининг» |

Исходные PNG (5,2 МБ) пережаты в WebP — вместе они весят 0,49 МБ, минус 91%.
Оригиналы остались в истории git, в коммите `76dfb23`.

## Аватарки — `assets/av/`

`man-01…10.webp` и `girl-01…10.webp`, по 320×320, обрезаны по кругу,
фон прозрачный. Показываются в выборе аватара в профиле.

Часть из них стоит в отзывах и у основателя:

| Файл | Где |
|---|---|
| `av/man-04.webp` | отзыв Тимура |
| `av/man-06.webp` | отзыв Марка |
| `av/girl-03.webp` | отзыв Анны |
| `av/man-01.webp` | основатель в блоке-призыве |

Исходные PNG (2,9 МБ) пережаты в WebP — 459 КБ, минус 84%.
Оригиналы остались в истории git, в коммите `7e01c54`.

Чтобы добавить ещё аватарок: положите файл `av/man-11.webp`
и поднимите `AV_COUNT` в `telegram.js`.

## Как пережимать новые

```bash
python3 -c "
from PIL import Image
im = Image.open('исходник.png').convert('RGB')
im.thumbnail((760, 760), Image.LANCZOS)
im.save('assets/имя.webp', 'WEBP', quality=86, method=6)"
```

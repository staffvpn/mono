# Картинки

Пути уже прописаны в `index.html`. Пока файла нет — на его месте видна
полосатая песочная заглушка. Положили файл с нужным именем — он появился сам.

## Присланные вами пять картинок

| Файл | Что на ней | Куда встаёт |
|---|---|---|
| `hero.jpg` | компания у жёлтого фургона в горах | большой квадрат справа в первом экране |
| `cat-1.jpg` | сантехник с разводным ключом | плитка «Ремонт и быт» |
| `cat-2.jpg` | курьер с коробками и телефоном | плитка «Курьерские задачи» |
| `cat-3.jpg` | разработчик за мониторами ночью | плитка «IT и разработка» |
| `cat-4.jpg` | уборка со шваброй и тележкой | плитка «Уборка и клининг» |

Большая — квадратная (1:1), четыре плитки — тоже квадратные (1:1),
так что кадрировать ничего не нужно.

## Остальные слоты (доделаете позже)

| Файл | Где используется | Размер |
|---|---|---|
| `rev-1.jpg` … `rev-3.jpg` | аватары в отзывах | 120×120, квадрат |
| `founder.jpg` | аватар основателя в блоке-призыве | 160×160, квадрат |

Форматы: `.jpg`, `.png` или `.webp` — при другом расширении поправьте путь
в `index.html` (ищите `--img:url(`).

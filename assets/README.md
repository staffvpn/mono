# Картинки

Сюда кладём изображения. Файлы подставляются автоматически — в HTML уже прописаны пути,
пока файла нет, на его месте показывается серо-зелёная заглушка.

| Файл | Где используется | Рекомендуемый размер |
|---|---|---|
| `hero.jpg` | большой блок на первом экране | 1400×1200, вертикально-квадратный |
| `task-thumb.jpg` | фото внутри карточки «Собрать шкаф» | 600×400 |
| `avatar-1.jpg` … `avatar-3.jpg` | три аватара под формой | 120×120, квадрат |
| `master.jpg` | карточка исполнителя в бенто-сетке | 600×800, вертикально |
| `cat-1.jpg` … `cat-4.jpg` | четыре карточки категорий | 700×1000, вертикально |
| `rev-1.jpg` … `rev-4.jpg` | аватары в отзывах | 120×120, квадрат |
| `founder.jpg` | аватар основателя в контактах | 120×120, квадрат |

Форматы: `.jpg` или `.webp` (тогда поправить расширение в `index.html`).

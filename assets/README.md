# Картинки

Сюда кладём изображения. Пути уже прописаны в `index.html` — пока файла нет,
на его месте видна песочная заглушка-градиент.

| Файл | Где используется | Рекомендуемый размер |
|---|---|---|
| `hero.jpg` | широкая полоса под заголовком первого экрана | 2000×880, горизонтально |
| `cat-1.jpg` … `cat-4.jpg` | четыре плитки направлений | 800×1060, вертикально |
| `rev-1.jpg` … `rev-3.jpg` | аватары в отзывах | 120×120, квадрат |
| `founder.jpg` | аватар основателя в блоке-призыве | 160×160, квадрат |

Форматы: `.jpg` или `.webp` (тогда поправить расширение в `index.html`).

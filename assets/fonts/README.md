# Шрифт Gramatika

Gramatika — коммерческий шрифт (Mint Type), его нет в Google Fonts и он не
распространяется свободно, поэтому файлы в репозиторий не положены.

Когда купите лицензию, положите сюда три файла — они подхватятся сами,
`@font-face` уже прописан в `styles.css`:

```
assets/fonts/Gramatika-Regular.woff2   (400)
assets/fonts/Gramatika-Medium.woff2    (500)
assets/fonts/Gramatika-Bold.woff2      (600)
```

Если у вас другие форматы (`.otf`, `.ttf`), сконвертируйте в `woff2` —
он весит в разы меньше и поддерживается всеми браузерами.

Пока файлов нет, сайт использует Onest — геометрическую гротеск-антикву
с похожим рисунком и полной кириллицей.

# tasko — лендинг сервиса задач

Статический сайт: люди размещают задачи («собрать шкаф», «починить стиралку»,
«сделать Telegram-бота», «отвезти документы»), исполнители их выполняют.

## Стек
Чистый HTML + CSS + JS, без сборки. Шрифт — Onest (Google Fonts).

## Локальный запуск
```bash
npx serve .
# или
python3 -m http.server 3000
```

## Структура
```
index.html    вся разметка страницы
styles.css    стили и адаптив (брейкпоинты 1180 / 1080 / 980 / 760 / 560)
script.js     меню, аккордеон, формы, появление блоков
assets/       картинки (см. assets/README.md)
vercel.json   конфиг деплоя
```

## Секции
Шапка → первый экран → манифест → бенто-сетка → таблица актуальных задач →
карточки категорий → отзывы и статистика → тарифы → FAQ → контакты → подвал.

## Деплой
Проект статический, деплоится на Vercel как есть — без build-команды.
